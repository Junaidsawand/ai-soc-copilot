## [0.1.0] - 2026-07-31

### Added
- **Core Architecture:** Modular Monolith leveraging FastAPI, PostgreSQL, and Flutter Web.
- **AI Orchestrator:** Integration with OpenAI API for processing JSON alerts.
- **Parsers:** Initial support for parsing standard Wazuh JSON exports.
- **Reporting:** Automated PDF and Markdown generation for investigation results.
- **Documentation Suite:** Comprehensive PRD, Architecture, Database Design, API Specs, AI Design, UI/UX, Deployment, Security, Developer, and User guides.
- **Infrastructure:** Docker and Docker Compose configuration for local development.
